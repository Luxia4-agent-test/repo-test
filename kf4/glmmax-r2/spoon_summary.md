# Spoon-Knife 요약

octocat/Spoon-Knife 저장소는 GitHub에서 저장소를 포크하는 방법을 보여 주는 예제 저장소다.

가장 큰 파일은 README.md(780바이트)로, 포크가 타인 프로젝트의 개인 사본을 만드는 행위이며 원본 저장소와 변경 사항을 주고받는 다리 역할을 한다는 내용을 담고 있다. 또한 이 저장소를 포크해 변경을 연습해 보고, 포크에 대한 자세한 내용은 GitHub 가이드 "Forking Projects" 문서를 참고하라고 안내한다. README.md에는 'fork'라는 문자열이 대소문자 구분 없이 총 8회 등장한다(단어 일부 포함).
